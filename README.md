## 🌐 Dokumentasi Kegiatan Workshop Day 1

### 1. Rangkuman Materi
Pada sesi Day 1, materi dibagi menjadi dua pilar utama yang sangat krusial bagi mahasiswa vokasi:

* **Sosialisasi Kurikulum MBKM & MSIB**
  * Kebijakan Kemendikbudristek yang memberikan hak belajar hingga 3 semester di luar program studi asal.
  * Pembelajaran fleksibel yang diakui dan dikonversi maksimal hingga 20 SKS per semester.
  * Program unggulan **MSIB (Magang dan Studi Independen Bersertifikat)** yang bermitra dengan industri terbaik untuk mencetak lulusan siap kerja.
  * Metode pembelajaran modern berbasis *Project-Based Learning* (PjBL), *Problem-Based Learning* (PBL), dan *Case-Based Learning* (CBL).

* **Technical Skill: Prompt Engineering & Version Control (Git & GitHub)**
  * **Prompt Engineering:** Seni merancang instruksi (prompt) yang spesifik agar AI memberikan jawaban tepat dan relevan. Struktur prompt yang baik terdiri dari komponen: *Role, Task, Context,* dan *Format*.
  * **Git:** Sistem pengontrol versi (*Distributed Version Control System*) yang berjalan secara lokal di komputer untuk melacak setiap perubahan file.
  * **GitHub:** Platform berbasis web untuk menyimpan repositori Git secara daring (online) sekaligus alat kolaborasi tim.
  * **Git Workflow:** Alur kerja file yang berpindah dari *Working Directory* (lokal), menuju *Staging Area* (indeks persiapan), hingga disimpan permanen di *Git Directory / Repository* melalui perintah commit.

### 2. Poin-Poin Penting & Pengetahuan Baru
* **Kunci Keberhasilan AI ada pada Konteks:** Menggunakan AI tanpa menyertakan latar belakang dan batasan (*constraints*) hanya akan menghasilkan jawaban yang umum dan kurang akurat.
* **Perbedaan Git dan GitHub:** Git adalah alatnya (*software*), sedangkan GitHub adalah rumahnya (*cloud hosting/platform*).
* **Perintah Dasar Git yang Wajib Dikuasai:**
  * `git init` (memulai repositori baru).
  * `git add .` (memindahkan perubahan ke staging area).
  * `git commit -m "pesan"` (menyimpan riwayat perubahan).
  * `git push origin main` (mengunggah kode lokal ke GitHub).
* **Keamanan SSH Key:** Penggunaan SSH key dengan algoritma Ed25519 memberikan performa tinggi dan keamanan enkripsi yang lebih kuat saat menghubungkan perangkat lokal ke akun GitHub.
